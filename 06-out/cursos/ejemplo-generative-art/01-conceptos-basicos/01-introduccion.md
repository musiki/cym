# ¿Qué es el Arte Generativo?

El arte generativo es una práctica artística donde el artista crea sistemas autónomos que pueden generar obras de arte de manera independiente o semi-independiente.

## Características principales

1. **Autonomía**: El sistema tiene reglas propias
2. **Variabilidad**: Cada ejecución puede producir resultados diferentes
3. **Emergencia**: Patrones complejos surgen de reglas simples

## Historia

El arte generativo tiene raíces en:
- Arte cinético (años 50-60)
- Computer art (años 60-70)  
- Fractales y sistemas L (años 80)
- Processing y creative coding (años 2000)

## Ejemplos clásicos

- **John Conway**: Game of Life
- **Vera Molnár**: Pionera del arte por computadora
- **Casey Reas**: Co-creador de Processing
